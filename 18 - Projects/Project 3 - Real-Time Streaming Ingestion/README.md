# PRJ-03: Real-Time Fleet Streaming & Telemetry Pipeline

## 📌 Executive Summary
High-throughput event streaming engine ingesting continuous vehicle telemetry (GPS, speed, engine diagnostics) at 100+ events/sec using **Apache Kafka 4.0 in pure KRaft mode**, Confluent Schema Registry (Avro), **PySpark Structured Streaming**, and TimescaleDB with real-time Grafana dashboarding.
