# SQL-04 - Advanced Grouping Sets and Rollups

## Status
- [ ] Not Started

## Objective
Calculate multidimensional business aggregations across multiple grouping levels in a single database pass.

## Concepts
- **`GROUPING SETS`**: Computing multiple distinct group-by aggregations in a single query pass without multiple `UNION ALL` scans.
- **`ROLLUP`**: Hierarchical progressive sub-totals and grand totals (e.g., Year -> Quarter -> Month -> Total).
- **`CUBE`**: Computing all $2^N$ permutations of grouping dimensions.
- **The `GROUPING()` Helper Function**: Distinguishing actual NULL data values from NULLs generated by subtotal rows.

## Notes
### ROLLUP Example
```sql
SELECT 
    CASE WHEN GROUPING(region) = 1 THEN 'Grand Total' ELSE region END as region,
    CASE WHEN GROUPING(category) = 1 THEN 'All Categories' ELSE category END as category,
    SUM(sales_amount) as total_sales
FROM sales
GROUP BY ROLLUP (region, category);
```
