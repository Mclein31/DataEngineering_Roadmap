# 🏢 Microsoft Certified: Fabric Data Engineer Associate (DP-700)

## Overview
The Microsoft Fabric Data Engineer Associate (DP-700) is the official enterprise credential for data engineering within the Microsoft ecosystem. **It officially replaced the retired Azure Data Engineer Associate (DP-203) exam on March 31, 2025.**

---

## 📋 Exam Specification
- **Certification**: Microsoft Certified: Fabric Data Engineer Associate
- **Provider**: Microsoft
- **Current Status**: **ACTIVE (Current Replacement for Retired DP-203)**
- **Exam Code**: DP-700
- **Prerequisites**: None official
- **Recommended Experience**: Experience with enterprise data architecture, Delta Lake, Spark, and Microsoft Fabric
- **Cost**: $165 USD
- **Exam Format**: 40–60 multiple-choice and scenario questions
- **Duration**: 100–120 minutes
- **Passing Score**: 700 / 1000
- **Renewal / Validity**: 1 year (free annual online renewal)
- **Official URL**: [learn.microsoft.com/en-us/credentials/certifications/fabric-data-engineer-associate/](https://learn.microsoft.com/en-us/credentials/certifications/fabric-data-engineer-associate/)

---

## 📊 Exam Domains & Weightings

```text
Domain 1: Ingest and Transform Data (30–35%)
Domain 2: Design and Implement Data Solutions (30–35%)
Domain 3: Monitor and Optimize Data Solutions (30–35%)
```

### Domain 1: Ingest and Transform Data (30–35%)
- Ingestion: Fabric Data Factory pipelines, Dataflow Gen2, copying data between OneLake and external sources.
- Transformation: Fabric Spark notebooks, Delta Lake tables, Lakehouse files, T-SQL warehouse querying.

### Domain 2: Design and Implement Data Solutions (30–35%)
- OneLake Architecture: Shortcuts (S3, ADLS Gen2, Dataverse), Medallion architecture within a single unified tenant.
- Serving Tier: Direct Lake mode for Power BI datasets, SQL Analytics Endpoints.
- Security: OneLake data access security, workspace roles, item permissions.

### Domain 3: Monitor and Optimize Data Solutions (30–35%)
- Performance Tuning: Spark V-Order optimization, table partitioning, liquid clustering in Delta tables.
- Capacity & Governance: Fabric capacity monitoring, throttling prevention, Purview integration.
