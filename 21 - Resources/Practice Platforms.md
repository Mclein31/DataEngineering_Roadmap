# 🎯 Practice Platforms & Interactive Sandboxes

High-yield platforms for practicing SQL drills, systems navigation, algorithmic coding, and end-to-end data pipeline labs.

---

## 🏆 SQL & Database Sandboxes
1. **Select Star SQL**
   - **URL**: [selectstarsql.com](https://selectstarsql.com/)
   - **Cost**: 100% Free
   - **Focus**: Interactive in-browser SQL learning with real execution on Texas death row dataset.
   - **Associated Lessons**: [[SQL-01 - Relational Execution Order]] through [[SQL-03 - Relational Joins and Anti-Joins]].
2. **DataLemur**
   - **URL**: [datalemur.com](https://datalemur.com/)
   - **Cost**: Free Tier (covers 100+ SQL interview drills)
   - **Focus**: Real FAANG/enterprise SQL interview questions tagged by difficulty and company.
   - **Associated Lessons**: [[50 High-Frequency SQL Drills]].
3. **pgexercises**
   - **URL**: [pgexercises.com](https://pgexercises.com/)
   - **Cost**: 100% Free
   - **Focus**: Structured PostgreSQL exercises spanning joins, recursive CTEs, aggregations, and window functions.
4. **Use The Index, Luke!**
   - **URL**: [use-the-index-luke.com](https://use-the-index-luke.com/)
   - **Cost**: 100% Free Web Book
   - **Focus**: Relational indexing mechanics, B-Trees, execution plan tuning.
   - **Associated Lessons**: [[SQL-11 - Execution Plans with EXPLAIN]] through [[SQL-14 - Indexing Strategies and B-Trees]].

## 🐧 Linux & Terminal Training
1. **Linux Journey**
   - **URL**: [linuxjourney.com](https://linuxjourney.com/)
   - **Cost**: 100% Free
   - **Focus**: Interactive POSIX navigation, file permissions, shell piping, text wrangling.
   - **Associated Lessons**: [[LNX-01 - Shell Navigation and Permissions]] through [[LNX-06 - Networking Fundamentals for DE]].
2. **SadServers**
   - **URL**: [sadservers.com](https://sadservers.com/)
   - **Cost**: Free
   - **Focus**: Scenario-based Linux troubleshooting on live ephemeral virtual machines.
